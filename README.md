# FactCheck App

My final year project, a full-stack fact-checking platform built with React, Express JS, and MySQL. Users can submit claims which are then reviewed and verified by factcheckers and editors.

Visit the app at: https://factcheck.mark0s.com

## User Roles

### Submitters
- Submit claims with one or more supporting sources
- Track claim status as it moves through the review pipeline
- View verdicts returned on their claims and raise disputes

### Fact-checkers
- Browse and take on available claims for verification
- Add annotations and evidence to support their findings
- Save work in progress and mark a review as complete when done

### Editors
- Triage incoming claims, assign to fact-checker or open pool or reject
- Monitor the progress of all claims across the platform
- Review completed fact-checks, publish verdicts, and view the full audit trail for each claim
- Handle disputes raised by submitters against published verdicts
